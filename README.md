# Orbit Forge · 轨道实验室

一个可以加入天体、改变初速度并检查守恒量的二维引力实验。TypeScript、原生 Canvas 和 Vite；无 API、账户或服务端。中文界面，适配桌面与手机。

## 本地运行

```sh
npm ci
npm run dev
```

开发地址：`http://127.0.0.1:5187`。生产预览为 `npm run build` 后 `npm run preview`，端口 `4187`。

```sh
npm test                 # 编译纯模型并运行 Node 测试
npm run build            # TypeScript 检查与 Vite 生产构建
npx playwright test --list
# 真实浏览器测试在 GitHub Actions 安装 Chromium 后运行
npm run test:e2e
```

## 操作

- 选择行星绕星、双星或三体初始条件。前两种按本模型软化后的引力计算圆轨道初速度，并使总动量和质心从零开始；恒星同样运动。
- 暂停、单步、改变播放速度或视野。画布获得焦点时，空格切换播放；N 单步。
- 用位置、初速度和质量表单加入天体，或开启放置模式，在画布按下选位置、拖动箭头设速度、松开加入。两种方式使用同一添加逻辑，最多 8 颗。箭头 1 个坐标单位对应速度分量 1；表单是完整的键盘替代。
- 添加会暂停、将模拟时间归零，并建立新的能量基准。重置回到最近选择的预设或载入的分享快照，移除之后加入的天体。
- 快照链接保存每颗天体的质量、位置、速度、标识与已积分步数。打开快照后暂停，以收到的状态建立新能量基准。它不保留原实验的能量基准或轨迹历史。
- PNG 保存当前画布及模型参数。展开“查验系统”可读取总动量、质心和每颗天体的数据。

## 物理模型及限制

这是二维、点质量、无量纲的牛顿引力近似，设 `G = 1`，没有转换到米、秒、千克、天文单位或真实天体；不是天文预测工具。

采用固定 Plummer 形式的软化长度 `ε = 0.06`。对两个天体，令 `r = rⱼ − rᵢ`：

```text
aᵢ += G mⱼ r / (|r|² + ε²)^(3/2)
aⱼ -= G mᵢ r / (|r|² + ε²)^(3/2)
Uᵢⱼ = −G mᵢ mⱼ / sqrt(|r|² + ε²)
K = Σ ½ mᵢ |vᵢ|²
E = K + Σᵢ<ⱼ Uᵢⱼ
```

势能与引力使用相同软化。成对累加保证相互作用力等大反向，避免把一个中心天体固定在屏幕上。显示圆点的尺寸只是辨识标记；模型没有物理半径、接触、碰撞、合并、碎裂、阻力或相对论。重叠位置保持有限相互作用，天体可以穿过彼此。

Velocity Verlet 固定 `Δt = 0.002`：位置更新后重新计算加速度，再完成第二次半步速度更新。播放速度只改变单位墙钟时间安排的固定步数，不使用屏幕帧间隔替代模拟步长。相同初始状态执行相同步数的结果与渲染分组无关。后台标签不积累追赶量；负载较高时限制每帧工作量，模拟会慢于墙钟目标，绝不扩大物理步长。轨迹只是最近的显示采样，不是未来预测。

相对能量漂移显示 `(E − E₀) / |E₀|`。当 `|E₀| < 10⁻¹²` 时不显示百分比，改显示绝对能量变化。用户添加、重置或载入预设/快照时重新建立 `E₀`，并给出提示。切换播放速度、轨迹或视野不会重建基准。近距离相遇仍可使固定步长误差变大；超过 1% 时界面提示检查条件，这个阈值不是精度保证。三体预设不承诺周期或长期稳定。为避免损坏快照和数值溢出，模型限制质量、坐标、速度、步数和天体数量；超出范围时暂停并保留上一次有效状态。

## 验证覆盖

纯模型测试包含：不等质量的反作用力、势能梯度与软化引力的一致性、圆轨道半径与能量漂移、三体总动量与质心、时间反演、固定步数分组复现、重叠不合并、零能量基准、快照精确往返与恶意输入。

圆轨道回归计算 20,000 个固定步，要求两体间距偏差小于 `2 × 10⁻⁵`、相对能量漂移小于 `10⁻⁶`。这是特定测试场景的容差，不代表任意输入下的精度。总动量与质心测试容差为 `10⁻¹⁰`。

Playwright 在桌面及手机视口验证控制、添加、重置、8 体上限、指针速度映射、画布缩放比例、预设、快照与无效链接、PNG 下载，并监听脚本和控制台错误及页面横向溢出。浏览器测试不以 DOM 存在替代模型正确性。
